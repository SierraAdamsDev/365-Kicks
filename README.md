# 365 Kicks

**365 Kicks** is a culture-forward digital publication dedicated to long-form sneaker journalism.

The platform publishes one in-depth feature per month, exploring sneaker history, design, and cultural influence — with a strong focus on women’s evolving role in the industry.

---

## Current Feature

**She’s Gotta Have Kicks: From The Margins to The Mainstream — Women’s Role in Sneaker Culture**

An editorial examining how women have shaped sneaker culture from overlooked contributors to industry drivers.

---

## Project Overview

This site is designed as a modern editorial experience featuring:

- Structured long-form article layout  
- Centered media presentation  
- Integrated YouTube, Spotify, Twitter/X embeds  
- Responsive design architecture  
- Custom visual identity rooted in sneaker culture  

The design balances bold color (red, magenta, black) with editorial readability and intentional whitespace.

## Design System Highlights

The article layout follows a structured editorial format:

- Left-aligned narrative text for readability  
- Centered images and embedded media  
- Caption styling beneath visual elements  
- Controlled max-width column for consistent spacing  
- Subtle motion and gradient overlays on landing page  

Example media structure used throughout the article:

```html
<figure class="article-media">
  <iframe src="VIDEO_OR_EMBED_URL"></iframe>
  <figcaption class="media-caption">Caption text here</figcaption>
</figure>
```

Global layout constraint example:

```css
.article-wrap {
  max-width: 950px;
  margin: 3.5rem auto;
  padding: 0 2.5rem;
  text-align: left;
}
```
